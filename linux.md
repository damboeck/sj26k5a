# Installation

* Packetlisten nachladen:
  >apt-get update

* Paket installieren:
  >apt-get install -y <paketname>
  
* htop installieren:
  >apt-get install -y htop
  
# wichtige Kommandos
* ls - Liste aller Dateien und Verzeichnisse
* ls -al - Liste aller Dateien und Verzeichnisse inkl. versteckter Dateien
* cd <verzeichnis> - Verzeichnis wechseln
* cd ~ - ins Home-Verzeichnis wechseln
* cd .. - ins übergeordnete Verzeichnis wechseln
* pwd - aktuelles Verzeichnis anzeigen
* whoami - aktueller Benutzer
